02 / Open one interval

Half-open labels [start, end): touching is not overlap

The interval audit

Three tests, in order

  1. Test membership. A contiguous block of event indices, balanced to differ in size by at most one. Starts are strictly increasing; event lengths vary.
  2. Label overlap. For every candidate i and test j, require start[i] < end[j] and start[j] < end[i]. Any positive intersection purges i. End-to-start contact alone is allowed.
  3. Post-test embargo. B is the latest label end among test events. Exclude a remaining candidate when its start is in [B, B + embargo). This is a duration in invented ticks, not a row count.

Classification precedence: TEST, PURGED, EMBARGO, TRAIN. Overlap counts and durations are computed for non-test candidates only. Retained means it passes this contract, not that it is independent or safe for deployment.

Intervals, not row gaps.

Two labels can share future outcomes even when their row indices differ. This engine merges the exact test-label union and audits every overlap pair. It does not replace variable horizons with a fixed row gap or a single convex-hull purge.

Seed changes starts and label lengths. Horizon changes label lengths, never prediction times. The seeded generator is a fixture, not a market process. All time arithmetic and counts are exact integers.

An explicit embargo.

Implementations differ on embargo anchors, row counts versus durations and endpoint inclusion. Here it starts at the latest test label end and excludes starts below B + embargo, with zero duration excluding nothing. No universal embargo length is implied.

An empty training set is a valid warning, not a reason to silently weaken the split. No fallback, model fit or accuracy score is produced.

One leakage channel.

Purging does not fix future-aware features, globally fitted scalers or selectors, revised data, duplicate entities, repeated tuning on a holdout or regime shifts. Embargo does not guarantee independence.

Fit learned transformations within each training split. These invented labels contain no outcomes or features, so no empirical leakage bias, generalization, investment edge or performance improvement is measured. Native Safari/Android untested.
